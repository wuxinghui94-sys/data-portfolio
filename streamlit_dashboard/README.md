# 渠道投放 ROI 与转化分析实时看板（脱敏 Demo）

> **作者**：吴幸晖 ｜ 数据分析师 / 商业数据分析  
> **安全说明**：本开源演示版已彻底剥离原企业飞书/CRM 密钥与真实业务数据，改为内置**高仿真模拟 API 数据引擎**，完整保留原生产环境看板的业务指标口径、加权聚合逻辑、多维交互分析与一键 Excel 导出能力。

## 核心功能亮点

1. **三业务线独立分析**：支持侧边栏一键切换「项目 A（高客单主营线）」「项目 B（体验营增长线）」「项目 C（新客孵化线）」。
2. **三大分析视角**：
   - 🎯 **期次明细复盘**：单期次核心经营大盘卡片、核心渠道置顶聚焦、转化率 & ROI 双图对比、透视明细表及 Excel 导出。
   - 📈 **渠道跨期对比**：智能加权合并同期次分段渠道数据；支持“全期次大盘汇总”与“细分渠道 PK”自由切换，全选渠道自动折叠单线防杂乱。
   - 🗓️ **月度数据看板**：支持全项目月度汇总与 **分团队月度 PK（A组 / B组 / C组）**，内置单渠道团队横向透视与多渠道拉通大表。
3. **严谨业务口径**：
   - 正式课退单率 = `正式课退单 / (正式课退单 + 总成交单数)`
   - 直播转化占比 + 私聊转化占比实时拆解
   - 点击侧边栏 `🔄 模拟实时刷新` 可模拟接口拉取最新实时增量数据

## 本地运行方式

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 3 分钟免费部署公网链接（Streamlit Community Cloud）

1. 将本 `streamlit_dashboard` 文件夹上传至你的 GitHub 公开仓库（如 `channel-roi-demo`）。
2. 访问 [https://share.streamlit.io](https://share.streamlit.io) 并用 GitHub 登录。
3. 点击 **New app** → 选择刚上传的仓库 → Main file path 填 `app.py` → 点击 **Deploy!**。
4. 等待 1~2 分钟即可获得免费永久公网链接（如 `https://wuxinghui-roi-demo.streamlit.app`），直接粘贴到简历与作品集首页即可！
